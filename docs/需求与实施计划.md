# 需求与实施计划

## 项目目标

构建可本地部署的企业级 RAG 知识库问答系统，让用户基于授权文档进行可追溯问答，支持管理员治理、异步入库和生产运维。

## 非功能要求

- 业务数据使用 MySQL，向量数据使用 Qdrant，异步任务使用 Redis/Celery。
- 生产环境使用不可变 SHA 镜像，不在部署主机本地构建大镜像；发布依赖生产环境到 GHCR 的稳定网络连通性。
- API、Worker、Frontend 必须支持健康检查、日志和故障排查。
- `.env`、密钥、备份和生产文件不得进入 Git。
- 所有权限在后端校验，不能只依赖前端隐藏界面。

## 实施阶段

### 阶段一：基础环境

完成 Python 3.12、FastAPI、Vue、MySQL、Redis、Qdrant、Docker Compose 和环境变量模板。

### 阶段二：认证与权限

完成客户端/管理端分离认证、会话刷新、CSRF、注册审批、用户状态、知识库成员和三种知识库角色。

### 阶段三：文档入库

完成格式校验、SHA-256 去重、文件存储、PDF/Office/文本解析、LangChain 切分、Celery 异步任务、失败重试和状态展示。

### 阶段四：RAG 问答

完成 Embedding、Qdrant 检索、标签过滤、相似度阈值、Top-K、来源引用、DeepSeek 提示词、多轮会话和 SSE 流式输出。

### 阶段五：企业能力

完成 OCR、音频转写适配、摘要、信息抽取、表格问答、模型管理、Token 用量与成本统计、审计日志、运行概览和生产检查脚本。

### 阶段六：交付与部署

完成测试、前端构建、GitHub Actions CI、GHCR 镜像、受控部署通道、健康检查、备份和回滚说明。
