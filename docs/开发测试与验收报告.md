# 开发测试与验收报告

## 开发流程

1. 使用 Python 3.12 创建 `.venv312`。
2. 安装 `requirements-dev.txt`，复制 `.env.example` 为 `.env`。
3. 启动 MySQL、Redis 和 Qdrant。
4. 修改后先运行相关测试，再运行全量测试。
5. 运行前端类型检查和生产构建。
6. 检查 `git diff --check`，确认没有冲突标记和无关文件。

## 测试命令

```powershell
& .\.venv312\Scripts\python.exe -m pytest backend/app/tests -q
cd frontend
npm run typecheck
npm run build
```

检索质量评测：

```bash
python scripts/evaluate_retrieval.py backend/app/evaluations/retrieval_cases.json --k 3 --output reports/retrieval-baseline.json
```

## 验收清单

- 客户端和管理端独立登录，互不覆盖会话。
- 注册、审批、停用和密码重置流程可用。
- 支持的文档能进入 `ready` 状态并产生分段。
- OCR 开启后图片能识别中文和英文。
- 配置转写服务后音频能进入 `ready` 状态。
- 失败文档显示原因，重试和批量索引有效。
- 问答支持标签、来源、页码、多轮会话和流式输出。
- 所有者、编辑者、查看者权限符合预期。
- `/health` 返回 database、redis、qdrant 均为 `ok`。
